# Gravity Books SQL Data Analysis

## Project Overview

This project analyzes the Gravity Books relational database using SQL
to identify business opportunities related to product demand,
customer behavior, author performance, and warehouse optimization.

## Business Questions

1. Which book language has the lowest demand?
2. Which author should be selected for a special promotion?
3. Which 10 customers should the sales team contact?
4. Where should Gravity Books locate a new warehouse?

## Technologies

- SQL
- Relational Database
- Joins
- Aggregations
- GROUP BY
- ORDER BY
- LEFT JOIN
- Business Intelligence
- Data Analysis

## Database

The Gravity Books database contains 15 related tables connected
through primary and foreign key relationships.

## Analysis

### 1. Language Demand

The analysis identifies languages with the lowest order volume.

### 2. Author Promotion

The analysis identifies the author with the highest number of
books sold.

### 3. Customer Segmentation

The analysis identifies the top 10 customers based on order volume.

### 4. Warehouse Optimization

The analysis identifies cities with the highest order volume to
support warehouse-location decisions.

## Business Recommendations

- Review low-demand languages and optimize inventory.
- Promote high-performing authors.
- Create loyalty programs for high-value customers.
- Consider warehouse locations in high-demand cities.
- Analyze shipping costs to optimize fulfillment.
